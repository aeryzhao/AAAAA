# 中国5A级景区大全

收录中华人民共和国文化和旅游部评定的全部国家5A级旅游景区的静态网站。

## 功能特性

- **景区浏览** — 卡片式展示所有5A景区，包含名称、简介、图片、入选年份等信息
- **多维筛选** — 支持按省份/地区、景区类别、入选年份筛选
- **关键词搜索** — 支持按景区名称、城市、省份、简介内容模糊搜索
- **景区详情** — 点击卡片弹出详情弹窗，展示完整介绍、坐标、百度百科链接
- **图片画廊** — 弹窗内支持多图切换浏览（带导航箭头和指示点）
- **分页浏览** — 每页20条，支持页码跳转
- **响应式布局** — 适配桌面端和移动端

## 技术栈

- 纯静态单页应用（HTML + CSS + JavaScript），无需构建工具
- 数据内嵌于 `index.html`，图片资源存放于 `images/` 目录
- 使用 Playwright 爬取百度百科数据生成景区图片

## 项目结构

```
├── index.html            # 主页面（含全部样式、逻辑和数据）
├── images/               # 景区图片资源
├── images-mapping.json   # 景区名称 → 本地图片路径映射
├── baike-urls.json       # 景区名称 → 百度百科词条映射
├── download-baike.mjs    # 百度百科数据爬取脚本
├── download-images.mjs   # 景区图片下载脚本（Playwright）
├── download-images.sh    # 图片下载 Shell 辅助脚本
├── fix-baike.mjs         # 百度百科数据修复/清洗脚本
└── package.json          # Node.js 依赖（Playwright）
```

## 本地运行

直接用浏览器打开 `index.html` 即可，或使用任意静态文件服务器：

```bash
# Python
python3 -m http.server 8080

# Node.js
npx serve .
```

## 数据来源

数据来源于中华人民共和国文化和旅游部公开发布的国家5A级旅游景区名录，截至2024年最新评定批次。
